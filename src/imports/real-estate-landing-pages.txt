Create a Figma file containing three desktop landing page templates for real estate agents at a luxury brokerage. These pages are designed for QR-code marketing and lead capture. The aesthetic should reflect luxury real estate branding similar to Sotheby’s International Realty: elegant, minimal, high-end, editorial typography, generous white space, clean grid layout.

Design three distinct templates labeled:

Template 1 — Personal Brand

Template 2 — Area Specialist

Template 3 — Home Search Funnel

Each template must be built using Auto Layout, reusable components, and consistent variables for dynamic data fields.

Frame width: 1440px desktop
Grid: 12 column grid
Margins: 80px
Gutter: 24px

Typography style:

Headline: elegant serif (Didot / Playfair Display style)

Body: modern sans-serif (Inter / Helvetica style)

Color palette:

Deep navy primary (#0B1F3B)

White background

Light grey sections

Gold accent lines or buttons

Black text

Buttons must have hover states and consistent styles.
